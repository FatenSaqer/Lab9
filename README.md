# Lab9
This project analyzes a loan dataset to predict whether a borrower will fully repay a loan using machine learning techniques. The workflow begins with exploratory data analysis (EDA) to understand key features such as FICO score, interest rate, and loan purpose. Categorical variables like “purpose” are converted into numerical form using dummy variables. The data is then split into training and testing sets, and two models—Decision Tree and Random Forest—are trained and evaluated. Performance is assessed باستخدام classification reports and confusion matrices, showing that the Random Forest model outperforms the Decision Tree by achieving higher accuracy and better handling of imbalanced classes. Overall, the project demonstrates how ensemble methods can improve predictive performance in financial risk analysis.
